# Kiste

A distributed, risk-aware, hardware-adaptive container control layer that sits between silicon and application. It’s a coordination layer across heterogeneous compute.

## Go project configuration

This repository is now configured as a Go module.

### Requirements
- Go 1.22+

### Run
```bash
go run .
```

### Build
```bash
go build -o bin/kiste .
```

### Test
```bash
go test ./...
```
